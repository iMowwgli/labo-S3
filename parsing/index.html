01Lexing et parsing (rappel)

  • Lexing : texte → liste de tokens.
  • Parsing : faire comprendre le texte au programme.
  • Le lexing mâche, le parsing digère.
  • Résultat du parsing : une structure de données, souvent un arbre syntaxique.
  • Mardi : CSV à la main (libc) + JSON avec une bibliothèque fournie.
"energie": 12.5   ─ lexer ─▶   STRING(energie)  COLON  NUMBER(12.5)   ─ parser ─▶   paire { clé:"energie", nombre:12.5 }

03 bisLes fonctions dispo par format

Mardi : libc uniquement. Les bibliothèques externes sont là pour la culture (et le QCM).

CSV

  • fgets(buf, size, f) : lit une ligne.
  • buf[strcspn(buf, "\r\n")] = '\0' : coupe la fin de ligne.
  • strtok_r(s, ",", &save) : découpe (fusionne ,,).
  • strchr(s, ',') : prochaine virgule (garde les champs vides).
  • isspace((unsigned char)c) : pour le trim.
  • strtol(s, &end, 10) / strtod(s, &end) : texte → nombre, avec contrôle.
  • Lib externe libcsv : csv_init, csv_parse, csv_fini, csv_free.

JSON

  • libc : rien de prévu → lexer + parseur à la main (missions 4 et 6).
  • isdigit, isalpha, isspace : type du caractère.
  • strncmp(p, "true", 4) : mots-clés.
  • printf("%.*s", len, start) : afficher un morceau sans copier.
  • cJSON : cJSON_Parse, cJSON_GetObjectItemCaseSensitive, cJSON_ArrayForEach, cJSON_IsString, cJSON_Print, cJSON_Delete.
  • jansson : json_loads, json_object_get, json_array_foreach, json_string_value, json_dumps, json_decref.
  • json-c : json_tokener_parse, json_object_object_get_ex, json_object_get_string, json_object_put.

YAML

  • libc : rien, et trop complexe à la main (indentation, listes, ancres).
  • libyaml : yaml_parser_initialize, yaml_parser_set_input_file, yaml_parser_parse (événements), yaml_event_delete, yaml_parser_delete.
  • Pour mardi : savoir le reconnaître, c'est tout.

04Lire l'entrée

  • Ligne par ligne : fgets(buf, sizeof buf, f) → CSV, INI, logs, Makefile.
  • fgets garde le '\n' : buf[strcspn(buf, "\r\n")] = '\0'; l'enlève (et le \r).
  • Fichier entier en mémoire → lexer / parseur (on a besoin de regarder en avant).
  • Toujours tester fopen et malloc.
static char *read_file(const char *path)
{
    FILE *f = fopen(path, "rb");
    if (!f)
        return NULL;
    fseek(f, 0, SEEK_END);
    long size = ftell(f);         // taille du fichier
    rewind(f);
    char *buf = malloc(size + 1);  // +1 pour le '\0'
    if (!buf) { fclose(f); return NULL; }
    size_t n = fread(buf, 1, size, f);
    fclose(f);
    buf[n] = '\0';
    return buf;                     // à free() par l'appelant
}

Le trim, à savoir écrire les yeux fermés

static char *trim(char *s)
{
    while (isspace((unsigned char)*s))   // cast obligatoire (UB sinon)
        s++;
    char *end = s + strlen(s);          // strlen UNE fois
    while (end > s && isspace((unsigned char)end[-1]))
        end--;
    *end = '\0';
    return s;                              // pointe DANS le buffer d'origine
}

Couper sur le 1er = sans strtok

06Convertir des nombres : strtol / strtod

  • atoi("12abc") → 12, atoi("abc") → 0 : aucune erreur détectable.
  • strtol te dit où il s'est arrêté via endptr.
  • Rien lu : end == s. Déchets après : *end != '\0'.
  • strtod pareil pour les flottants.
char *end;
long v = strtol(s, &end, 10);
if (end == s || *end != '\0')
    /* pas un entier valide */;

07sscanf : parser une ligne au format fixe

  • Renvoie le nombre de champs remplis → toujours le tester.
  • %s s'arrête au 1er espace. Toujours une largeur : %63s.
  • %[A-Z] : que des majuscules. %[^:] : tout sauf :.
  • Un espace dans le format = « 0 ou plusieurs blancs ».
  • Un caractère littéral ([, :) doit être présent… mais un échec après le dernier % ne change pas le retour !
  • %n = nb de caractères consommés : seul moyen de savoir si la fin a matché.
// "2026-11-08 06:12:44 [WARN] recycleur: oxygene a 23%"
char date[11], time[9], level[10], module[64];
int msg = -1;
if (sscanf(line, "%10s %8s [%9[A-Z]] %63[^:]: %n",
           date, time, level, module, &msg) != 4 || msg < 0)
    /* ligne invalide */;
char *message = line + msg;      // "oxygene a 23%"
%n ne compte pas dans le retour de sscanf. Initialise-le à -1 : s'il vaut encore -1, le ":" final n'a pas été trouvé.

08Formats « ligne par ligne » : CSV et INI

CSV

  • 1re ligne = en-tête → à sauter.
  • Espaces après les virgules (comme dans le CM) → trim chaque champ.
  • Champs vides possibles ? Alors pas de strtok : boucle sur strchr(p, ',').
char *save = NULL, *fields[4];
int n = 0;
for (char *t = strtok_r(l, ",", &save); t && n < 4; t = strtok_r(NULL, ",", &save))
    fields[n++] = trim(t);

INI

  • [section] → mémoriser la section courante (copie, pas pointeur : le buffer ligne sera écrasé !).
  • cle = valeur → couper au premier =.
  • Commentaires ; ou # en début de ligne.
  • Chaque ligne qui n'est rien de tout ça = erreur avec numéro de ligne.
Piège classique : section = l + 1; garde un pointeur vers line, que le prochain fgets écrase. Copie avec snprintf(section, sizeof section, "%s", ...).

JSON 1cJSON : ce que le parseur te rend

  • cJSON_Parse lit tout le texte et rend la racine d'un arbre.
  • Chaque nœud est un cJSON *.
  • Les enfants d'un objet/tableau = liste chaînée (child, puis next).
  • Conséquence : accéder au i-ème élément coûte O(i).
typedef struct cJSON {
    struct cJSON *next, *prev;  // frères (liste chaînée)
    struct cJSON *child;        // 1er enfant (objet / tableau)
    int type;                  // cJSON_String, cJSON_Number, ...
    char *valuestring;         // si string
    int valueint;              // si nombre (TRONQUÉ, à éviter)
    double valuedouble;        // si nombre ✔
    char *string;              // la CLÉ si le nœud est dans un objet
} cJSON;
Bibliothèque fournie : le jour J tu auras sûrement cJSON.c + cJSON.h dans ton dossier (comme lib/ du kit).
#include "cJSON.h" et compile cJSON.c avec ton code (ou utilise le Makefile fourni).
Si c'est une autre lib : même logique, voir la table « Si c'est une autre lib ».

JSON 2Lire du JSON : les 6 étapes

  • 1. Lire le fichier dans un buffer.
  • 2. cJSON_Parse(buf) → racine, ou NULL si JSON invalide.
  • 3. Naviguer : cJSON_GetObjectItemCaseSensitive, cJSON_ArrayForEach.
  • 4. Vérifier le type : cJSON_IsString, IsNumber, IsArray…
  • 5. Lire la valeur : ->valuestring, ->valuedouble.
  • 6. cJSON_Delete(racine) : libère tout l'arbre.
Étape 1 : la fonction read_file du chapitre « Lire l'entrée ».

Étapes 2 → 6 · exemple complet

char *text = read_file(argv[1]);
if (!text) { fprintf(stderr, "Erreur : lecture\n"); return 1; }

cJSON *root = cJSON_Parse(text);
free(text);                           // l'arbre est indépendant du texte
if (!cJSON_IsArray(root)) {             // IsArray(NULL) == false : couvre aussi l'échec
    fprintf(stderr, "Erreur : JSON invalide\n");
    cJSON_Delete(root);                // Delete(NULL) ne fait rien : OK
    return 2;
}

const cJSON *m;
cJSON_ArrayForEach(m, root) {
    const cJSON *nom = cJSON_GetObjectItemCaseSensitive(m, "nom");
    const cJSON *en  = cJSON_GetObjectItemCaseSensitive(m, "energie");
    if (!cJSON_IsString(nom) || !cJSON_IsNumber(en))
        continue;                         // champ absent ou mauvais type
    printf("%s : %.2f\n", nom->valuestring, en->valuedouble);
}
cJSON_Delete(root);

JSON 3Écrire du JSON

  • cJSON_CreateObject() / cJSON_CreateArray() créent un nœud.
  • cJSON_AddStringToObject, AddNumberToObject, AddBoolToObject… ajoutent un champ.
  • cJSON_AddArrayToObject(obj, "k") crée et ajoute un tableau, et te le rend.
  • cJSON_AddItemToArray(arr, item) : l'arbre devient propriétaire de item.
  • Donc un seul cJSON_Delete sur la racine suffit.
  • cJSON_Print (indenté) / cJSON_PrintUnformatted (une ligne) allouent → free.
cJSON *root = cJSON_CreateObject();
cJSON_AddStringToObject(root, "station", "Kepler-7");
cJSON *crew = cJSON_AddArrayToObject(root, "equipage");

cJSON *p = cJSON_CreateObject();
cJSON_AddStringToObject(p, "nom", "Ada");
cJSON_AddNumberToObject(p, "age", 41);
cJSON_AddItemToArray(crew, p);      // p appartient maintenant à crew

char *s = cJSON_PrintUnformatted(root);
puts(s);                            // {"station":"Kepler-7","equipage":[{"nom":"Ada","age":41}]}
free(s);
cJSON_Delete(root);

09 · BONUSÉcrire un lexer à la main

  • Un pointeur p avance dans le texte.
  • On regarde *p et on décide quel token commence ici.
  • Blanc → on avance. Symbole simple → 1 caractère.
  • Chaîne / nombre / mot → on avance tant que ça continue, le token = [start, p).
  • Aucune règle ne marche → erreur lexicale avec ligne et colonne.
  • Pas besoin de copier : printf("%.*s", (int)(p - start), start) affiche le morceau.
while (*p) {
    if (*p == '\n') { line++; col = 1; p++; continue; }
    if (isspace((unsigned char)*p)) { col++; p++; continue; }
    const char *start = p;
    if (*p == '{') { puts("LBRACE"); p++; }
    else if (isdigit((unsigned char)*p)) {
        while (isdigit((unsigned char)*p)) p++;
        printf("NUMBER(%.*s)\n", (int)(p - start), start);
    }
    else if (strncmp(p, "true", 4) == 0 && !isalnum((unsigned char)p[4])) { puts("TRUE"); p += 4; }
    else { fprintf(stderr, "Erreur lexicale ligne %d colonne %d\n", line, col); return 2; }
    col += p - start;
}
Une chaîne "a\"b" : quand tu vois \, saute deux caractères, sinon le \" ferme la chaîne trop tôt.

10 · BONUSParseur à descente récursive

  • On écrit la grammaire, puis une fonction par règle.
  • Chaque fonction consomme ce qu'elle reconnaît et renvoie 1 (ok) ou 0 (erreur).
  • Le curseur p est partagé (global ou const char **).
  • Une erreur remonte simplement par les return 0.
  • Valider tout avant d'afficher si la consigne veut « rien sur stdout en cas d'erreur ».
objet  := '{' [ paire { ',' paire } ] '}'
paire  := STRING ':' valeur
valeur := STRING | NUMBER | true | false | null
static int parse_object(void)
{
    skip_ws();
    if (*p++ != '{') return 0;
    skip_ws();
    if (*p == '}') { p++; return 1; }       // objet vide
    for (;;) {
        if (!parse_pair()) return 0;
        skip_ws();
        if (*p == ',') { p++; continue; }      // "," puis OBLIGATOIREMENT une paire
        if (*p == '}') { p++; return 1; }
        return 0;
    }
}
Pas de copie des chaînes : stocke des slices { const char *s; int len; } qui pointent dans le buffer du fichier. Zéro malloc, zéro fuite.

11 · BONUSRappel Minimake

  • NOM = valeur → variable.
  • cible: dep1 dep2 → règle.
  • Ligne qui commence par TAB → commande de la règle courante.
  • $(NOM) → remplacé par la valeur (vide si inconnue).

// Expansion en UN passage : on écrit dans out en avançant
while (*src) {
    char *close;
    if (src[0] == '$' && src[1] == '(' && (close = strchr(src + 2, ')'))) {
        const char *val = lookup(src + 2, close - src - 2);
        size_t vl = strlen(val);
        memcpy(out + o, val, vl);   o += vl;
        src = close + 1;
    } else
        out[o++] = *src++;
}
out[o] = '\0';

12Erreurs et mémoire

  • Messages d'erreur → stderr. Résultats → stdout.
  • Codes de retour : respecte la consigne à la lettre (1, 2, 3…).
  • Tout chemin d'erreur ferme ce qu'il a ouvert (fclose, free).
  • Buffer fixe ? Toujours la taille dans le format (%63s) ou snprintf.
  • valgrind --leak-check=full ./prog fichier avant de rendre.
