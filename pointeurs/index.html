      Zéro fuite

      • 1 malloc = 1 free.
      • Vérifier le retour de malloc, realloc, fopen.
      • realloc dans une variable tmp.
      • next = NULL à la création.
      • free(value) avant free(nœud).
      • Garder next avant le free.
      • Rien après un free.
      • En erreur, ne pas libérer ce qu'on t'a donné.
      • fclose sur tous les chemins, free(line) après getline.

      Lire les outils de debug

      heap-use-after-freelecture après un free
      buffer-overflowindice hors du tableau, souvent <=
      memory leaksun malloc sans free
      uninitialised valuevariable jamais initialisée
      definitely lostfuite (Valgrind)
      backtraceligne du segfault (GDB)

      Pièges vus en TP

      • = au lieu de == dans un if.
      • if (strcmp(a, b)) est vrai si elles sont différentes.
      • int i contre size_t count : warning, donc erreur.
      • sizeof(struct node), pas sizeof(struct node *).
      • *list = (*list)->next pour avancer détruit la liste.
      • char c = fgetc(f) : EOF mal détecté, il faut un int.

      Cas limites à tester

      • Paramètre NULL.
      • Liste ou fichier vide.
      • Un seul élément.
      • Indice 0, indice = taille, hors limites.
      • Dernière ligne sans \n.
      • Valeurs négatives (ne pas initialiser un max à 0).
