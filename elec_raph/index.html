Les trois modes, côté composant

Méthode pour reconnaître le mode

  1. Regarde Vbe (ou Ib). Sous 0,6 V, ou si Ib = 0, rien ne circule dans la base : le transistor est bloqué. Alors Ic = 0 et Vce = Vcc.
  2. Regarde Vce. Autour de 0,2 V, le transistor est un interrupteur fermé : il est saturé. Sans mesure, calcule Ic max = (Vcc − 0,2) / Rc et compare avec β × Ib : si β × Ib ≥ Ic max, il sature.
  3. Sinon, Vce est entre 0,2 V et Vcc et Ic = β × Ib : il est linéaire.

Ici : transistor NPN au silicium, β = 100, Vbe de conduction 0,6 V, Vce de saturation 0,2 V.
